# ceej-skills

## Project memory

This project uses the trivia MCP. All memories are tagged `project:ceej-skills`
and follow the trivium taxonomy in `trivium/TAXONOMY.md` (seeds,
`habits/<theme>` hubs, and `worked` / `avoid` / `learned` spokes). Open
sessions with `session-start`, close them with `session-retro`, and run
`memory-gardening` when lessons stop surfacing.
